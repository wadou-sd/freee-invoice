# 決算賞与 勤怠査定 仕様書

## 目的
7月決算の決算賞与にあたり、従業員の勤怠(出勤・休日・欠勤)を集計し、
所定公休との差分から賞与への勤怠影響を判定する。毎年7月に実施。

## 査定期間
- 事業年度に対応: 前年6/21 〜 当年6/20（freee締め 21日〜20日 × 12支払月）
- 例: 2025年度 = 2025/6/21〜2026/6/20（ちょうど365日）

## 入力
- freee人事労務 → 出勤簿PDF（従業員別・12か月分）
  取得: [勤怠] → 年月と締め日支払日グループを選択 → [出力] → 勤怠サマリー/出勤簿
- 所定年間公休: 105日（通期在籍者）

## 集計項目（従業員別）
- 労働日数（※有休を含む。freee出勤簿の定義。実出勤＋有休）
- 実出勤日数 = 労働日数 − 有休
- 有休取得日数（日次の「有休」表記を集計）
- 欠勤日数
- 特別休暇（忌引等）
- 公休 = 在籍日数 − 労働日数 − 欠勤 − 特別休暇
  （＝出勤簿の空欄日。有休は労働日数側に含まれ公休には入らない）

## 判定
実公休 vs 所定105日 の差分：
- ±0 : 正常
- 負  : 所定より多く出勤（減額対象外。むしろ貢献側）
- 正  : 所定超過（中身を精査。病欠 / 振替 / 打刻漏れ の別を確認）

## 個別ルール
- 加藤裕: 別休日制度（1/1〜5/31 隔週2日［2日→1日→2日…］／6/1〜12/31 週休2日、所定≒93日）
- 期中入社者: 在籍日数で所定を按分
  例) 櫻井=入社2025/7/1・在籍355日 → 所定 105×355/365 ≒ 102日

## 減額（勤怠に起因する場合）
- 所定超過が私傷病(病欠=欠勤)の場合、賞与減額の対象
- 所定出勤日数 = 365 − 所定公休105 = 260日
- 出勤率換算 = 欠勤日数 ÷ 260
- 減額率 = 会社決定（2025年度は6%。換算値5.4%を会社方針で6%に設定）
- ※就業規則・賃金規程の病欠時/出勤率の定めを優先。規程整合は社労士確認（当システムは算定補助）

## 成果物
勤怠サマリー_賞与査定_YYYYMM-YYYYMM.xlsx
- タブ: サマリー / 出勤内訳・公休 / 賞与減額シミュレーション /
        休務・遅刻早退 / 労働時間 / 労働日数 / 欠勤日数 / 有休取得日数 /
        特別休暇 / 要確認事項
- 減額シミュレーション: 基本賞与(黄色セル)を入力 → 減額後・減額分を自動算出

## 毎年の手順
1. freee人事労務から全従業員の出勤簿PDF(12か月)を出力
2. 各人の月別「労働日数・欠勤・有休」と、日次の有休/欠勤/特別休暇/遅刻早退を集計
3. 公休を算出し、所定(105。個別ルール・按分を適用)との差分を判定
4. 所定超過者は中身(病欠/振替/打刻漏れ)を確認し、病欠は欠勤へ計上
5. 減額率を確定し、基本賞与を入力して減額後を算出
6. work_log.md に当年度の実績と決定事項を追記
